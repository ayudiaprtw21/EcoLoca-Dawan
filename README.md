# EcoLoca-Dawan
ECOLOKA (Edukasi, Colaborasi, dan Lokakarya Kesehatan serta Aksi Lingkungan) adalah aplikasi web untuk masyarakat dan petugas di wilayah kerja Puskesmas Dawan I. Fiturnya mencakup panduan pemilahan sampah, panduan Teba Cacah, kalkulator perkiraan hasil dan waktu pengomposan, serta pencatatan inspeksi kesehatan lingkungan.
